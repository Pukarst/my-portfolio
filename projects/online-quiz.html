Online Quiz
Management System

A role-based platform designed to simplify quiz creation, examination management, and student performance tracking.

PythonDjangoBootstrapSQLite

The problem

Making assessment
easier to manage.

Managing quizzes, examination attempts, scoring, and student progress across different user roles requires a single, organized application. This project brings those workflows together in a Django-based platform.

The platform supports separate Admin, Teacher, and Student experiences, with quiz administration and student assessment flows.

What it does

FEATURES
01

Role-based access

Dedicated Admin, Teacher, and Student experiences.

02

Quiz authoring

Manage quizzes and questions for online examinations.

03

Assessment

Online attempts with automatic grading and score tracking.

04

Progress views

Quiz history, leaderboards, performance reports, and dashboards.

My focus included backend architecture, authentication, database design, quiz management, and application functionality.

Technology choices: Django and Python for server-side application logic, SQLite for data persistence, and Bootstrap for responsive interface components.
